# Generates the Gene Ontology table

Generates the Gene Ontology table

## Usage

``` r
ingest_gene_ontology_relations(obo_list)
```

## Arguments

- obo_list:

  Named list. Output of
  [`parse_gene_ontology()`](https://gregorlueg.github.io/genewalkR/reference/parse_gene_ontology.md)

## Value

A data.table with the Gene Ontology relationships
