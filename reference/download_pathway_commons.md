# Helper function to download the pathway commons data

Helper function to download the pathway commons data

## Usage

``` r
download_pathway_commons(
  target_path,
  url = "https://download.baderlab.org/PathwayCommons/PC2/v14/pc-hgnc.txt.gz"
)
```

## Arguments

- target_path:

  String. Where do download the data

## Value

Downloads the necessary files to target_path.
