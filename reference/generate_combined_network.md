# Combine

Combine

## Usage

``` r
generate_combined_network(
  interactions_string,
  interactions_signor,
  interactions_reactome,
  interactions_intact,
  interactions_pc
)
```

## Arguments

- interactions_string:

  data.table. STRING interactions.

- interactions_signor:

  data.table. SIGNOR interactions.

- interactions_reactome:

  data.table. Reactome interactions.

- interactions_intact:

  data.table. Intact interactions.

- interactions_pc:

  data.table. Pathway commons interactions.

## Value

The data.table with the Intact interaction
