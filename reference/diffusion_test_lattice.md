# Create a lattice graph for diffusion testing

Create a lattice graph for diffusion testing

## Usage

``` r
diffusion_test_lattice(n_side = 10L)
```

## Arguments

- n_side:

  Integer. Side length of the square lattice.

## Value

A named list with `graph` (igraph), `edges` (data.frame), and
`node_names` (character vector).
