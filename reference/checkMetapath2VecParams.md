# Check metapath2vec parameters

Checkmate extension for the output of
[`params_metapath2vec()`](https://gregorlueg.github.io/genewalkR/reference/params_metapath2vec.md).

## Usage

``` r
checkMetapath2VecParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
