# Check diffusion profile parameters

Checkmate extension for the output of
[`params_diffusion_profiles()`](https://gregorlueg.github.io/genewalkR/reference/params_diffusion_profiles.md).

## Usage

``` r
checkDiffusionProfilesParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
